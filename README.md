# 🐝 Supply Chain Optimization using Artificial Bee Colony Algorithm

This project is a Python-based application that simulates and optimizes a **logistics/supply chain network** in Morocco using the **Artificial Bee Colony (ABC)** algorithm. The system is built with **Flask** for the web interface and **NetworkX** for graph modeling. Users can upload a supply chain network, run the ABC optimization, and visualize results step by step.

## 🚀 Features

- 🔍 Visual interface for uploading and managing supply chain graphs.
- 🐝 Custom implementation of the Artificial Bee Colony algorithm.
- 📊 Real-time tracking of optimization progress (fitness, bee distribution, stagnation).
- 🌍 Designed for regional supply chain optimization (e.g., Morocco).
- 💾 Data stored in `.graphml` format using NetworkX.

## 🛠 Tech Stack

- Python 3
- Flask
- NetworkX
- Bootstrap (for styling)
- HTML / JS (for frontend logic)
